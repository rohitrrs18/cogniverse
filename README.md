# 🌐 CogniVerse — Team Portfolio

A modern, responsive team portfolio website built to showcase **CogniVerse**, its members, projects, and collaborative work. Designed with a clean interface and smooth navigation to present the team's identity and development journey.

## ✨ Features

- **Home Page** — Introduction to CogniVerse and its vision.
- **Team Page** — Showcase team members and their profiles.
- **Projects Page** — Display projects with descriptions and details.
- **Reusable Components** — Modular cards, navigation, and footer components.
- **Responsive Design** — Optimized for desktop, tablet, and mobile.
- **Modern UI** — Clean layouts and consistent styling.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/cogniverse-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd cogniverse-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 📦 Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
